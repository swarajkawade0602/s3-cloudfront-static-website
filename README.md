# AWS Static Website Hosting 🚀

This project demonstrates how to host a static website using Amazon S3 and deliver it globally using CloudFront for high performance and scalability.

---

## 📌 Overview

A static website is deployed on Amazon S3 and distributed through CloudFront CDN to ensure low latency, high availability, and faster content delivery across regions.

---

## 🛠️ Tech Stack

* **Amazon S3** – Static website hosting
* **Amazon CloudFront** – Content Delivery Network (CDN)
* **HTML5 & CSS3** – Frontend

---

## 🚀 Features

* 🌍 Global content delivery using CloudFront
* ⚡ Fast and low-latency performance
* 📦 Highly scalable architecture
* 💰 Cost-effective hosting solution

---

## ⚙️ Deployment Steps

1. Create an S3 bucket
2. Enable static website hosting
3. Upload website files (HTML, CSS, images)
4. Configure bucket policy for public access
5. Create a CloudFront distribution pointing to the S3 bucket
6. Access the website using the CloudFront URL
